# 数据源验证清单

本文件是待执行清单，不代表接口已开通或已完成测试。请通过具备权限的账户与供应商确认，并避免在仓库中保存密钥、个人联系方式或未经授权的完整返回数据。

## 企查查

1. 申请所需企业招聘和企业核验能力；确认主体、用途、数据留存和 CRM 使用是否获准。
2. 从现有企业资源库通过授权方式准备 20 家南京候选企业的名称或统一社会信用代码；无法核验的企业保持待核验，不凭名称合并。
3. 记录每次调用日期、接口、企业标识、页数、返回状态、结果数量和实际计费；不要记录密钥。
4. 对照真实响应确认招聘日期、办公地点、企业主体、数据时效、分页、重复记录及是否支持日期筛选；确认历史覆盖范围和频率限制。
5. 用最少必要的授权样本验证解析和去重；区分“未返回记录”“接口失败”和“没有招聘需求”。

企查查招聘接口的具体能力和价格以账号开通后的合同及实际响应为准。本项目先将其作为已知候选企业的信号补充，候选企业发现需要另外的数据来源。

## 58 授权数据

核实是否有企业办公室求租数据，以及能否按南京鼓楼区和 100～300㎡筛选；确认历史覆盖、新数据推送、企业识别、授权联系渠道、CRM 使用、留存期限、费用和调用限制。未获批前保持该来源不可用，不实施非授权采集。
